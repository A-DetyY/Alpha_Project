# 聊天对话界面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建全屏 RPG 深色风格聊天界面，支持用户输入中文消息并由系统随机延迟回复。

**Architecture:** 三个脚本解耦：`SystemResponder`（纯 C# 类）封装回复逻辑，后续只改此文件即可扩展；`MessageItem`（MonoBehaviour）负责单条消息渲染；`ChatManager`（MonoBehaviour）协调 UI 交互与数据流。场景和 Prefab 通过 Unity Editor 手动搭建。

**Tech Stack:** Unity 2022.3.56f1c1, UGUI (ScrollRect + VerticalLayoutGroup + ContentSizeFitter), TextMeshPro 3.0.7 (Dynamic Atlas), 阿里巴巴普惠体 TMP Font Asset

## Task 5: ChatManager

**Files:**
- Create: `Assets/Scripts/Chat/ChatManager.cs`

- [ ] **Step 1: 创建脚本**

新建文件 `Assets/Scripts/Chat/ChatManager.cs`：

```csharp
using System.Collections;
using TMPro;
using UnityEngine;
using UnityEngine.UI;

public class ChatManager : MonoBehaviour
{
    [SerializeField] private ScrollRect scrollRect;
    [SerializeField] private Transform messageContainer;
    [SerializeField] private TMP_InputField inputField;
    [SerializeField] private Button sendButton;
    [SerializeField] private GameObject systemMessagePrefab;
    [SerializeField] private GameObject userMessagePrefab;

    private SystemResponder _systemResponder;

    private void Awake()
    {
        _systemResponder = new SystemResponder();
        sendButton.onClick.AddListener(OnSendClicked);
        inputField.onSubmit.AddListener(_ => OnSendClicked());
    }

    private void OnDestroy()
    {
        sendButton.onClick.RemoveListener(OnSendClicked);
    }

    private void OnSendClicked()
    {
        string text = inputField.text.Trim();
        if (string.IsNullOrEmpty(text)) return;

        AddMessage(text, userMessagePrefab);
        inputField.text = string.Empty;
        inputField.ActivateInputField();
        StartCoroutine(ShowSystemReply(text));
    }

    private IEnumerator ShowSystemReply(string userMessage)
    {
        yield return new WaitForSeconds(Random.Range(0.5f, 1.5f));
        AddMessage(_systemResponder.GetReply(userMessage), systemMessagePrefab);
    }

    private void AddMessage(string text, GameObject prefab)
    {
        Instantiate(prefab, messageContainer).GetComponent<MessageItem>().SetContent(text);
        Canvas.ForceUpdateCanvases();
        scrollRect.normalizedPosition = Vector2.zero;
    }
}
```
